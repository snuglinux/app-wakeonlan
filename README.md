WakeOnLan for ClearOS

The plugin adds a web interface for managing Wake-on-LAN in ClearOS.
Main functionality

    Adding, editing and deleting devices.
    Saving the name, MAC address and IP address of the device.
    Launching devices via Wake-on-LAN from the web interface.
    Displaying the availability status of devices by IP.
    Selecting the local IPv4 address of the interface from which the WOL packet will be sent.
    Support for an optional Broadcast IP address.
    Ukrainian and English localization.

The plugin is convenient for administering computers, servers and other network devices without physical access to them.
